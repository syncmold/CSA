# 一張自評表只走一條直線的簽核流程，自評單位不並行

控制活動類的自評表有多個自評單位（資材、品保、財務…），但所有關卡排成一條直線依序簽核，例如「資材自檢 → 資材主管 → 品保自檢 → 品保主管 → … → 稽核主管」，不讓各單位同時作答。這是使用者的明確要求：自評表照固定順序傳遞，不拆單；每個關卡用可編輯範圍限制只能改自己單位的控制要點，避免誤改前面簽核人的答案。代價是後面的單位要等前面的單位簽完，整體耗時較長。

## Considered Options

- **單位並行、最後合流到廠區經理人**：比較快，但流程狀態變成多條分支，退回與追蹤都複雜得多，也不符合紙本的傳遞習慣。
- **每個自評單位拆成獨立的自評表**：最簡單，但同一份問卷的整體結論與簽核欄會被拆散，PDF 不再是一份完整的紙本對應。
