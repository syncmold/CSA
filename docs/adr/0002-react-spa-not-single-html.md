# 前端用 React SPA，不沿用小組「單一 HTML 檔＋原生 JS」的慣例

小組其他系統（PMP、WMS 等）都是單一 HTML 檔加原生 JS；本系統刻意偏離，改用 React＋TypeScript＋Vite 的單頁應用，編譯成靜態檔，一樣放在免費的靜態主機。原因是本系統有五種介面語言、流程編輯器、範本編輯器與四種角色的畫面，單一檔案預估超過一萬行而無法維護；小組慣例源自過去的開發人力限制，不是技術上的需要。各模塊的選型理由與更換影響見 `docs/前端技術選型說明.md`。

## Consequences

- 部署多一道編譯步驟；接手維護的人需要會 React 與 TypeScript。
- 無法複製 PMP 的單檔做法直接套用，登入等共用流程要以本系統的架構重新實作。
